# 邮件服务配置与部署

## 配置方式

报名邮件、匿名信箱通知和私密回信共用 `spring.mail` 发件配置。发件账号和 SMTP 授权码支持环境变量覆盖，也可以使用 JAR 外部的配置文件，不需要修改 Java 代码。

163 邮箱的 SMTP 密码应填写客户端授权码。邮箱网页登录密码不用于本项目的 SMTP 配置。

本地私密配置位于项目根目录的 `config/application.properties`，已加入 Git 忽略规则，不会被 Maven 打包进 JAR。当前 IDEA 后端的运行目录为项目根目录，因此启动时会自动加载该文件。换用其他运行目录时，需要显式指定配置文件的位置。

`config/application.properties.example` 是不含真实凭据的配置模板。不要用模板覆盖已经填写好的私密配置。

## 服务器部署

将本地的 `config/application.properties` 单独上传到服务器。下面以应用目录 `/www/bdis` 为例，配置文件存放在 `/www/bdis/config/application.properties`。

在后端原有启动命令中追加配置参数，其他 JVM 参数、环境变量和应用参数保持原有设置：

```bash
--spring.config.additional-location=file:/www/bdis/config/application.properties
```

例如从命令行启动：

```bash
java -jar /www/bdis/bdis-website-0.0.1-SNAPSHOT.jar --spring.config.additional-location=file:/www/bdis/config/application.properties
```

如果通过 systemd 或宝塔管理后端，请将该参数追加到对应服务的启动命令，然后重启后端。文件属主应为运行后端的用户，并限制读取权限：

```bash
chmod 600 /www/bdis/config/application.properties
```

Spring Boot 的外部配置会覆盖 JAR 内的对应配置。已有环境变量 `BDIS_MAIL_HOST`、`BDIS_MAIL_PORT`、`BDIS_MAIL_USERNAME`、`BDIS_MAIL_PASSWORD` 仍可用于原来的环境变量配置方式；不要同时配置两份不同的发件凭据。

正式部署还需要通过 `BDIS_JWT_SECRET` 提供服务器专用的随机 JWT 密钥，按 UTF-8 编码后至少 32 字节，并在服务重启时保持稳定。仓库中的 JWT 默认值是明确的本地开发示例，不能作为正式环境密钥。

## 收件地址与检查

发件邮箱与收件邮箱是两个独立设置：报名邮件的目标邮箱在后台“简历管理”设置中维护；匿名信箱管理员通知使用 `feedback.recipient` 或 `BDIS_FEEDBACK_RECIPIENT`；私密回信发送给提交者填写的回信邮箱。本次只配置发件服务，不修改这些收件地址。

后台显示“邮件服务已配置”只表示账号、授权码和发送组件已经提供，不等于实际收件箱已收到邮件。部署后应先确认该状态，再按需要使用专门的测试内容验收真实发送和收件。服务器需要能够连接 `smtp.163.com` 的 TCP 465 端口。
